# Absolution
Welcome to our third-person interactive combat game, where you can choose from 3 unique characters (each damned to hell for a certain reason) to survive and fight enemies.

## Controls

| Control | Action |
| ----- | ----- |
| WASD | Move |
| Space | Jump |
| Mouse | Look Around / Aim |
| Shift (Hold) | Sprint |
| Ctrl | Dodge (Slide if sprinting) |
| Left Mouse Button | Primary Attack |
| Middle Mouse Button | Lock Onto Nearest Enemy |
| Right Mouse Button | Block / Parry (Knight) |
| F | Primary Ability |
| R | Ultimate Ability | 
| C (Hold) | Crystal Sight (Fortune Teller) |
| V (Hold) | Meditate (Fortune Teller) |
| Esc | Unlock Mouse Cursor |

## Character Abilities
To provide a better and more fun player experience, each character class has a different set of abilities and moves. *Each character is able to climb, hold onto and run across walls. Jump into any wall to try this.*

### Jester (Melee)
- Is able to double jump. Pressing attack while up in the air triggers a **Plungle Slam**. 
- F - **Whip pull**: Can either pull smaller enemies towards the player, or the player to larger enemies. 
- R - **Untouchable**: Renders her temporarily invulnerable as every incoming attack is automatically dodged until the ability runs out.
### Fallen Knight (Melee)
- Holding right click blocks with the shield, reducing incoming attack damage.
- There is a short parry window, in which if the player is precise enough they can riposte the enemy's attack, dealing extra damage.
- F - **Spin Attack**: Deals AOE damage to nearby enemies.
- R - **Unkillable**: While active the knight cannot go below 1 health, making him unable to die.
### Fortune Teller (Ranged)
- F - **Tarot Draw**: Draws a random card with a certain effect. Tower and Death cards power up her next hit, while the star card refills mana, sun card heals her.
- R - **Fate Sealed**: All enemies in her sight are marked and every hit on them is a critical hit.
- C (Hold) - **Crystal Sight**: Reveals hidden items and gets rid of illusions near her.
- V (Hold) - **Meditate**: Regenerates mana at the cost of having to stand still.

#### Generative AI tools were occasionally used for:
- Debugging and simplifying complex mechanics, particularly after merging iterations made by different people into the main timeline.
- Identifying weak points in the structure of the game.
- Maths equations for animations, complex raycasting, suggesting appropriate numbers to balance the game and characters.
- Temporary effects before we created our own particle effects.
